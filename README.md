# Leetcode Solutions

我的 LeetCode 刷题记录和题解整理。

## 刷题记录

按主题分类整理常见算法题型和解题思路。

### 主要涵盖领域

- **数据结构**：数组、链表、栈、队列、树、图、哈希表
- **算法思想**：双指针、滑动窗口、二分查找、回溯、动态规划
- **高频题型**：字符串处理、链表操作、二叉树遍历、图论算法

## 内容组织

每道题包含：
- 问题描述和约束条件
- 解题思路和关键要点
- C++ 实现代码
- 时间和空间复杂度分析
- 个人思考和易错点总结

## 学习目标

- 系统掌握常见数据结构和算法
- 提升编码能力和问题分解能力
